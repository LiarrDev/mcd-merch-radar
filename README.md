# 📦 麦麦周边雷达 · MCD Merch Radar

> **一句话找出你附近门店现在能买到哪些麦当劳周边。**
> 官方菜单里没有「周边」分类，它们藏在汉堡薯条中间。

麦当劳程序员创意开发大赛参赛作品 · 基于**麦当劳中国 MCP** 开发 · 非麦当劳官方产品

---

## 😤 你有没有过这种时候

- 刷到别人晒「麦当劳联名复古棒球帽」，想去买，**不知道自家门口那家店有没有**
- 听说广州有「薯条脆卜卜毛绒周边」，跑到店里问，**店员说这家店不卖**
- 想集齐麦当劳的周边，只能在 App 里**一家店一家店翻完整菜单**，还得在汉堡和薯条之间找帽子
- 看到积分商城有「罗技键鼠套装 6666 积分」，兴冲冲点进去，**活动上周就结束了，但页面还挂着**

麦当劳的周边信息从来没有一个统一入口。
**这个工具就是把它们从菜单里挖出来，摊成一张表。**

---

## ✨ 它做什么

| 能力 | 说明 |
|---|---|
| 🔍 **跨店扫描** | 指定城市 → 自动取附近门店 → 逐店拉取在售菜单 → 抽出周边 |
| 📊 **分布矩阵** | 哪款周边 · 在哪些店 · 多少钱，一眼看全 |
| 🎯 **门店差异款** | 自动标出「并非所有门店都有」的款式 —— 这类最容易扑空 |
| 🗂️ **隐藏分类** | 告诉你它藏在 `小食甜品/其他` 还是 `开心乐园`，方便你自己去核实 |
| 🏷️ **纯周边 vs 套餐** | 「泷泷星愿四件套」是**含周边的套餐**，不是纯周边 —— 明确标注不误导 |
| ⏰ **积分周边校正** | 用服务器时间比对兑换窗口，**剔除已过期却仍标记「上架」的商品** |
| 🧾 **双输出** | Markdown 报告给人看，JSON 给程序用 |

## 🚀 快速开始

### 1. 申请 MCP Token

访问 <https://open.mcd.cn/mcp>，手机号登录后激活即可拿到 Token。

### 2. 安装

```bash
git clone https://github.com/LiarrDev/mcd-merch-radar.git
cd mcd-merch-radar

# 零第三方依赖，Python 3.9+ 直接可跑，无需 pip install
```

### 3. 运行

```bash
export MCD_MCP_TOKEN='你的Token'

# 默认扫描上海 / 北京 / 广州
python -m merch_radar.cli

# 指定城市与门店数
python -m merch_radar.cli --cities "成都市:春熙路,杭州市:湖滨" --limit 5

# 同时扫描积分限定周边
python -m merch_radar.cli --points

# 输出 JSON，或写入文件
python -m merch_radar.cli --json
python -m merch_radar.cli --out report.md
```

### 常用参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--cities` | 城市与定位词，`"城市:关键词,城市:关键词"` | 上海/北京/广州 |
| `--limit` | 每城最多扫描门店数 | 3 |
| `--points` | 同时扫描积分限定周边 | 关 |
| `--no-verify` | 跳过 `mall-product-detail` 二次校验（省调用） | 校验开启 |
| `--json` | 输出 JSON 而非 Markdown | 关 |
| `--out` | 同时把报告写入文件 | 无 |

> **调用量**：默认配置约 14 次调用，远低于 600 次/分钟限流。
> 增大 `--limit` 会线性增加调用（每店 1 次 `query-meals`）。

## 🧠 它是怎么认出周边的

麦当劳菜单**不告诉你哪些是周边**，所以识别规则是本项目最核心的部分。
这些规则是在真实数据上踩坑后校准的，每一条都有对应的误判案例：

### 两级规则

1. **名称关键词**（主）：`周边`、`联名`、`毛绒`、`百宝袋`、`按摩捶`、`痒痒挠`、
   `棒球帽`、`公仔`、`玩偶`、`限定饼干`、`吧唧`、`徽章`、`玩具`、`礼盒`、`保温杯`……
2. **标签命中**（辅）：官方 tag 含 `限量周边` → 归为「含周边的套餐」

### 踩过的坑（都在代码注释里）

| 误判风险 | 实际案例 | 处理方式 |
|---|---|---|
| 标签「同款」误伤 | `我就喜欢代言人同款` 会命中**厚薯泥培根肉酱双牛堡** —— 那是个汉堡 | 「同款」不能单独作为依据 |
| 标签「素龙饼干」误伤 | `泷盐星星麦旋风` 带此标签，本质是冰淇淋 | 名称关键词优先，标签只作辅助 |
| 套餐当成纯周边 | `泷泷星愿四件套` 是**含周边的套餐**，不是纯周边商品 | 单独归类为 `bundle`，输出明确标注 |

### 不做正则解析文本

麦当劳 MCP 在响应的 `structuredContent` 字段里直接返回业务结构化 JSON。
本项目**直接消费结构化字段**，不解析 markdown 文本 —— 少一层解析就少一层脆弱。

## ⚠️ 说明

- 本项目**全程只读**：只调用 `query-nearby-stores` / `query-meals` / `now-time-info` /
  `mall-points-products` / `mall-product-detail`，**不调用任何下单、兑换或领券接口**。
  是否购买由你自行决定。
- 周边库存与上架情况由门店实时决定，扫描结果仅代表**运行那一刻**的状态。
- 若门店返回菜单为空或接口异常，报告会明确标注该店扫描失败，不会静默跳过。
- 非麦当劳官方产品，数据以麦当劳官方渠道为准。
