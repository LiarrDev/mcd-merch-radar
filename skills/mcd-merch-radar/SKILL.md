# 麦麦周边雷达

麦当劳菜单**没有「周边」分类**——周边混在汉堡薯条之间。
这个 Skill 帮你把它们挖出来，并告诉你哪些店有、哪些店没有。

## 何时使用

- 用户想找麦当劳周边、联名款、玩具、限定商品
- 用户想知道某款周边在自己附近门店能不能买到
- 用户想比较不同门店 / 城市的周边差异
- 用户问积分商城能换什么周边

## 怎么用

项目根目录执行（需先设置 `MCD_MCP_TOKEN`）：

```bash
# 默认扫描上海/北京/广州，每城 3 家店
python -m merch_radar.cli

# 指定城市
python -m merch_radar.cli --cities "成都市:春熙路,杭州市:湖滨" --limit 5

# 同时查积分限定周边
python -m merch_radar.cli --points

# JSON 输出 / 写文件
python -m merch_radar.cli --json
python -m merch_radar.cli --out report.md
```

## 输出里有什么

- **分布矩阵**：哪款周边 · 在哪些店 · 多少钱
- **门店差异款**：并非所有门店都有的款式（最容易扑空，优先提醒用户）
- **隐藏分类**：它藏在 `小食甜品/其他` 还是 `开心乐园`，方便用户自己去核实
- **纯周边 vs 含周边套餐**：`泷泷星愿四件套` 这类是套餐送周边，不是纯周边商品，必须说清楚

## 回答用户时的要点

1. **先说门店差异款**。用户最可能扑空的就是这些。
2. **区分纯周边和套餐**。别把「泷泷星愿四件套」说成"能买到这个周边"——它是个套餐。
3. **标注扫描时间**。周边上架情况随时变，结果只代表那一刻。
4. **积分周边要说明状态**。接口 `status=2` 不可信，若工具标记「已过兑换期」，要明确告诉用户现在兑不了。
5. **不要替用户下单**。本项目全程只读，是否购买由用户自己决定。

## 已知限制

- 周边识别基于名称关键词 + 官方标签，可能漏掉命名不含关键词的新品
- 周边是门店维度，覆盖更多门店需增大 `--limit`，调用量线性增长
- 积分商城的限定周边常为「每日限量、整点开抢」型，档期极短，当前很可能无在架商品
